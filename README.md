## 📌 Overview  
This repository contains various HTML, JavaScript, and Node.js projects and practice files. It includes web pages, scripts, and implementations of different functionalities such as fetching data, handling forms, working with regex, and more.  

## 📂 Project Files  
- **Node.js** – Added Node.js-related files.  
- **HTML Files** – Various web pages such as:  
  - `portfolio.html` – Personal portfolio page.  
  - `cart.html` – Shopping cart functionality.  
  - `random_number.html` – Random number generator.  
  - `regex.html` – Regular expressions practice.  
  - `fetch.html` – Fetch API implementation.  
  - `prac.html`, `prac2.html` – Practice HTML files.  
  - `product_page.html` – Product listing page.  
  - `different_devices.html` – Responsive design testing.  
- **JavaScript Files** – Includes:  
  - `cart.js` – Handles cart operations.  
- **Images** – Used for various web pages:  
  - `head.jpeg`, `product.jpg`.
